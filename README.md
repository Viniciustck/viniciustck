## 🔎 Agregador Inteligente de Vagas

Sistema desenvolvido em **Java 17 e Spring Boot** para automatizar a busca por oportunidades de emprego.

O sistema coleta vagas de diferentes fontes, armazena e remove duplicidades com PostgreSQL, utiliza IA para identificar oportunidades relevantes e envia notificações automaticamente pelo Telegram.

### Stack

`Java 17` • `Spring Boot 3.2` • `PostgreSQL` • `Gemini AI` • `Telegram Bot` • `Docker` • `GitHub Actions`

### Funcionalidades

- 🔍 Agregação automática de vagas
- 🤖 Filtragem utilizando IA
- 🗃️ Deduplicação com PostgreSQL
- 📲 Notificações automáticas via Telegram
- ⏰ Execução automática várias vezes ao dia
- 🐳 Deploy com Docker
- 🚀 CI/CD com GitHub Actions
